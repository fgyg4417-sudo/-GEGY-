
GEGY IDLE — это легковесная, мультиадаптивная кроссплатформенная веб-среда разработки (IDE), написанная на чистом стеке HTML5, CSS3 (интегрирован Tailwind CSS) и JavaScript. Визуальный интерфейс приложения полностью смоделирован по каноническому образцу классического окна Python IDLE, обеспечивая чистый, академический и сфокусированный на коде опыт программирования.
Внутри приложения развёрнут полноценный авторский лексический интерпретатор (движок выполнения программ), интерактивная консоль Shell и симулятор графического 2D-дисплея, способные обрабатывать и выполнять скрипты с расширением .gegy.
## 🦾 Реальный технический функционал (Без бутафории)
В отличие от простых визуальных макетов («пустышек»), данная программная сборка содержит реальную математическую, логическую и алгоритмическую начинку. Вот честный список того, что на самом деле реализовано и работает в кодовой базе JavaScript-интерпретатора:
## 1. Настоящая интерактивная шина ввода-вывода (Консоль)

* Вывод данных (JU): Осуществляет честный вывод строковых и числовых значений в интерактивное окно Python Shell.
* Интерактивный ввод (JUI): Полностью рабочий блокирующий ввод данных с клавиатуры. Движок не имитирует ввод, а намертво приостанавливает поток выполнения программы (точно так же, как input() в Python), вызывая нативное системное диалоговое окно устройства prompt(). Введённые пользователем символы или числа сохраняются в оперативную память и обрабатываются алгоритмами скрипта дальше.

## 2. Динамические массивы и структуры данных общего назначения
Интерпретатор честно манипулирует ячейками выделенной памяти JavaScript для работы с массивами:

* ADD и SERT: Реальное динамическое расширение списков (добавление элемента в конец и точечная врезка по указанному индексу).
* CEL и SR: Полное обнуление массивов памяти и автоматическая сортировка элементов по алфавиту / возрастанию.
* decon: Системная очистка списков от повторяющихся дубликатов на базе структуры уникальных множеств Set.
* Оператор RERS: Честный и полностью отлаженный разворот исходного массива задом наперёд (.reverse()).
* Связка DEL ... BEL: Настоящая низкоуровневая операция извлечения элемента (pop). Она находит элемент по индексу, безвозвратно вырезает его из массива памяти, уменьшая размер списка, и передаёт извлечённое значение в назначенную переменную.

## 3. Вычислительные агрегаторы выражений (HiT)
Парсер способен вычислять математический приоритет и собирать информацию о структурах данных в выражениях:

* LN(arr) — возвращает реальную длину массива.
* SM(arr) — автоматически суммирует все числа внутри списка.
* jn(arr) / jx(arr) — находят минимальное и максимальное значения в массиве.
* copy(arr) — создаёт независимую поверхностную копию списка в новую переменную.

## 4. Ассоциативные карты Zim и Инспектор типов Tyis

* Конструктор Zim(keys, vals): Из двух независимых массивов (ключей и значений) на лету «сваривает» полноценную хэш-таблицу формата «Ключ: Значение». Поддерживается реальное чтение и динамическая перезапись параметров по квадратным скобкам (например, stats["gold"¡] := 500).
* Инспектор Tyis(var): Честно сканирует оперативную память приложения и определяет тип данных, возвращая строгие маркеры ("ARR", "MAP", "INT", "STR", "FLOAT"), либо выдаёт 1 или 0 при верификации на совпадение с шаблоном.

## 5. Логическое управление, Ветвления и Супер-циклы

* Развилки Er и DEF: Условные операторы (if/else) со стопроцентной поддержкой логических масок SA (И), OR (ИЛИ), xor/xSA (исключающее ИЛИ) и BAR (НЕ).
* Конструкция ECM: Аналог современного питоновского оператора match/case для сопоставления переменной с числовыми ветками-шаблонами.
* Цикл Raff: Классический счётчик итераций по заданному числовому диапазону.
* Супер-цикл Rafle: Продвинутый защищённый цикл, который на каждом шаге заново вызывает лингвистический анализатор условий FF (условие while). Если в процессе выполнения динамические параметры нарушаются, цикл безопасно затухает, предотвращая зависание вкладки браузера.

## 6. Аварийный контур безопасности

* Блоки TR ➔ CRT ➔ RST развёрнуты поверх системных предохранителей try/catch/finally. При возникновении ошибки (например, обращение к несуществующему ключу карты Zim или деление на ноль) программа не падает аварийно, а изолирует сбой, передавая системный код ошибки в переменную блока CRT для безопасной программной санации в блоке RST.

## 7. Графический симулятор рендеринга Vube (Важное уточнение)

* Интерпретатор успешно парсит команды инициализации буфера Vube(), очистки кадра FSE и вывода FSJ.
* При обработке векторных команд SVV (векторная линия) и PLOP (штамп спрайта) движок синхронизируется с элементом HTML5 Canvas и выводит базовые демонстрационные геометрические фигуры и текстовые маркеры объектов. На данном этапе геометрические параметры фигур зафиксированы внутри графического обработчика-обёртки для наглядной демонстрации работы рендера.

## 8. Автономная компиляция

* Функция верхнего меню генерирует независимый исполняемый .html файл с кодом пользовательского скрипта, позволяя скачивать готовые автономные мини-бандлы программ.

## 🛠️ Требования и развёртывание проекта
Проект полностью автономен, не требует сервера, Node.js, баз данных или скачивания внешних зависимостей.
Для запуска достаточно открыть файл index.html в любом современном веб-браузере (Google Chrome, Mozilla Firefox, Safari, Opera) как на персональном компьютере, так и на экране мобильного телефона.
